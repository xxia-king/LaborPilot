# 书面语体规范

适用于 LaborPilot 输出的全部书面文件，包括 `.docx` 和作为成果交付的 Markdown，内部分析稿也不例外。对话中的汇报可以用白话，写入文件的内容必须使用正式法律语言。《案件研判报告》的结构与推理规则另见[结构契约](case-report-contract.md)。

## 基本要求

- 使用法言法语和规范法律术语，不用行话、比喻和自造缩写。
- 每句话有主语和谓语，按正序说完整；不以分号串起的短语代替句子，不以“标签：短语”的形式开段。
- 结论在前，理由在后；一段只讲一个命题。
- 正式程度与篇幅无关。避免学术化的长句，但不以口语换取简短。

## 引用

- 法律、行政法规、司法解释首次出现写全称；需要简称时，在全称后注明“（以下简称《……》）”，之后统一使用该简称。
- 条款项序号写中文数字，例如“第三十九条第（二）项”；不使用 §、圈码或阿拉伯数字条号。
- 指导性案例写“最高人民法院指导性案例××号”，首次出现写明案例名称。
- 正文引用写法律全称加条款项序号，条文原文放入附件，不在正文和附件重复抄录。
- 已废止或效力未明的文件，只能作为历史参考并写明状态，不得作为现行依据。

## 禁用写法

以下写法由 `scripts/report_lint.py` 拦截，左列为禁用写法，右列为规范表述示例。

| 禁用写法 | 规范表述 |
|---|---|
| 2N | 二倍经济补偿标准的赔偿金 |
| N | 经济补偿 |
| N＋1 | 经济补偿及额外支付的一个月工资 |
| 翻盘 | 改判；推翻原审结论 |
| 抓手 | 依据；理由 |
| 讲透 | 充分阐明 |
| 打成0 | 改判为无需支付 |
| 零认定 | 未作认定 |
| 筹码 | 协商条件 |
| 主攻 | 主要理由 |
| 站得住 | 成立；依据充分 |
| 对向风险 | 对方上诉的风险 |
| 硬伤、坐实、撬动、打法 | 改用明确的法律表述 |

以下写法偏口语，校验时提示，应尽量改写：拉回、推回、真空期、增量、胜算、定价、突破口。

## 补丁段

复核意见应当改进原段落。以下句式表明意见被追加成了补丁段，校验时拦截：“但必须清楚”“需如实指出”“另需评估”“另有一处”“另需指出”“需要说明的是”“值得注意的是”“补充说明”。

## 表格

- 一张表只回答一个问题，不超过四列。
- 每格写一个规范短语，不超过 40 字，可以省略主语；论证理由、计算过程和法条依据放正文、表注或附件。
- 不写“败”“胜”“中低”这类需要读者猜测的标签，例如应写“我方败诉，涉及金额较小”。
- 内容重复的表格合并。

## 加粗与标点

- 加粗只用于关键句；整段加粗不超过三处。
- 中文正式内容使用全角标点，包括（）、【】、，、；、——。
