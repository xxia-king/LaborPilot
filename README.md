# LaborPilot

> 劳动争议智能办案引擎,内置执业律师构建的 96 卡争点知识体系

[![License: AGPL v3](https://img.shields.io/badge/License-AGPL%20v3-blue.svg)](https://www.gnu.org/licenses/agpl-3.0)

**⚠️ 免责声明:本引擎产出的所有分析结果和法律文书均由 AI 辅助生成,仅供参考,不构成法律意见,必须经专业律师审核后方可使用。**

## 项目概述

LaborPilot 是一个面向中国劳动争议案件的知识驱动型法律分析引擎,覆盖从案件材料摄取、争点识别、请求权基础分析、经济补偿与赔偿金计算,到仲裁文书生成的完整办案流程。支持劳动者方与用人单位方双视角,默认内置浙江省高级人民法院及浙江省劳动人事争议仲裁院系列裁判口径。

LaborPilot 的核心价值在于内置数据:完整的争点知识体系随引擎一并分发,无需联网检索、无需自备法律法规数据库,下载即获得与作者一致的知识库。

核心能力:

| 能力 | 说明 |
|------|------|
| 内置知识库 | 执业律师逐条构建、逐字核验的 96 卡争点知识体系,随引擎离线分发,开箱即用 |
| 争点识别 | 96 个争点知识卡,按《民事案件案由规定》组织为 23 个案由门,自动匹配案件事实与法律争点 |
| 请求权分析 | 逐项审查构成要件、举证责任分配、对方抗辩路径 |
| 金额计算 | 经济补偿(N/N+1/2N)、加班工资(150%/200%/300%)、工伤保险待遇(三笔一次性)等,精确到分 |
| 地方口径 | 浙江高院解答一至七、疑难纪要、仲裁指导意见的提炼与引用 |
| 文书生成 | 仲裁申请书、证据清单、行动清单,输出 .docx 格式 |

## 内置知识体系

区别于依赖联网检索、或要求用户自备数据库的法律 AI 工具,LaborPilot 的全部法律知识编译嵌入引擎本体:

- **执业律师人工构建**:96 张争点卡由执业律师基于法律法规、司法解释与裁判口径逐条构建、逐字核验,非网络爬取的碎片信息
- **全国规则与地方口径双层结构**:以《劳动合同法》《社会保险法》《工伤保险条例》《劳动争议司法解释(一)》《劳动争议司法解释(二)》及劳动和社会保障部规章为依据层;浙江高院解答一至七、疑难问题解答纪要、省劳动人事争议仲裁院系列意见全量纳入,96 张卡中 80 张内置浙江裁判口径
- **更新至最新规则**:已纳入《劳动争议司法解释(二)》(法释〔2025〕12 号)及最高人民法院第 42 批指导性案例(新就业形态劳动关系认定)
- **七维度结构化**:每张争点卡包含构成要件、法律依据(条文号)、举证责任分配、计算公式、仲裁时效、地方裁判口径、文书模板指向

知识数据已编译嵌入引擎,离线可用,版本随仓库发布统一更新。

## 安装

克隆或下载本仓库即可,核心功能开箱即用。可选增强:

| 功能 | 依赖 | 说明 |
|------|------|------|
| 文书生成 | [pandoc](https://pandoc.org) | Markdown → .docx 转换 |

| 法律数据校验 | 外接 MCP 数据源 | 条文号实时核验 |

## 使用

### 输入

支持多种输入形式:结构化 JSON、PDF 案卷材料、图片、自然语言案件描述。引擎自动完成材料摄取与要素提取。

以结构化 JSON 为例(`my_case.json`):

```json
{
  "case": {
    "申请人": "张某,男,1990年5月3日出生,住浙江省温州市",
    "被申请人": "某科技有限公司,住所地温州市鹿城区",
    "入职日期": "2022-03-01",
    "离职日期": "2025-06-15",
    "月工资": 8000,
    "未签书面合同": true,
    "未缴社保": true,
    "解除方式": "口头通知解除,未提前三十日,未支付经济补偿",
    "事实与理由": "2022年3月入职,月工资8000元。被申请人未签订书面劳动合同、未缴纳社会保险。2025年6月15日口头通知解除,未履行任何法定程序。"
  }
}
```

### 产出

```bash
python3 scripts/generate_docs.py --case my_case.json --output ./output
```

| 产出物 | 格式 | 内容 |
|--------|------|------|
| 劳动仲裁申请书 | .docx | 当事人、仲裁请求、事实与理由、落款 |
| 证据目录 | .docx | 证据名称、来源、页码、证明目的 |
| 行动清单 | .docx | 待核实事实、待补证据、金额核对、庭前行动 |

文书模板持续更新中,支持自定义加入。

### 争点查询

如需单独检索特定法律争点:

```bash
python3 scripts/issue_router.py --search "违法解除" --full
```

## 争点覆盖

82 张争点卡 + 14 张案由门卡,共 96 卡,分布如下:

| 争点域 | 卡数 | 覆盖争点 |
|--------|------|---------|
| 劳动关系认定与合同订立 | 7 | 确认劳动关系、未签书面合同二倍工资、应订无固定期限未订、试用期、电子劳动合同、劳务派遣、非全日制用工 |
| 解除与终止 | 15 | 协商解除、过失性解除(§39)、不能胜任解除(§40)、医疗期满解除、客观情况重大变化、经济性裁员(§41)、期满终止与退休终止(§44)、违法解除赔偿金(2N)、劳动者被迫解除(§38)、医疗期、三期女职工解除限制、服务期违约金、解除程序义务 |
| 追索劳动报酬 | 13 | 加班工资(150%/200%/300%及计算基数)、不定时与综合计算工时、工资总额组成、拖欠工资、最低工资、停工停产、高温津贴、农民工工资支付、未休年休假 300% 报酬、医疗期工资 |
| 经济补偿金 | 8 | 补偿年限(N)、高薪封顶(三倍社平+12 年)、月工资基数、代通知金(N+1)、2N 与 N 的关系、军龄工龄计入、违反劳动合同赔偿 |
| 竞业限制与保密 | 2 | 竞业限制(人员范围/补偿标准/违约金)、保密义务与竞业限制的区分 |
| 工伤保险待遇 | 11 | 工伤认定(三工+通勤)、视同工伤、职业病衔接、停工留薪期、伤残津贴、一次性伤残待遇、工亡待遇、第三人侵权竞合双赔、非法用工一次性赔偿、工伤职工解除限制、待遇免税 |
| 其他社会保险待遇 | 3 | 养老待遇损失、医疗生育待遇损失、失业保险金损失 |
| 福利待遇 | 3 | 婚丧产护育儿假(浙江天数)、女职工特殊劳动保护、法定节假日 |
| 特殊用工主体 | 7 | 超龄劳动者、超龄工伤、实习生、港澳台居民就业、违法发包/转包/挂靠用工主体责任、新就业形态用工(不完全劳动关系)、新就业形态职业伤害保障 |
| 人事争议 | 2 | 事业单位聘用合同、公务员及文职人员争议边界 |
| 程序性争点 | 11 | 仲裁时效、仲裁管辖(浙江)、一裁终局、保全与先予执行、举证责任分配、裁审衔接、调解协议效力、简易程序与要素式办案(浙江)、公民代理、撤诉与裁决生效、社保补缴受案范围 |
| 案由识别 | 14 | 各案由门内置请求权基础与构成要件审查,输入案件材料后自动匹配 |

## 架构

```
案件材料
   ↓
LaborPilot 引擎
├── 知识数据(96 争点,预编译)
├── 争点路由(自动匹配案由)
├── 金额计算引擎
└── 文书生成器
   ↓
分析结果 + 仲裁申请书 + 证据目录
```

争点卡为作者独立构建的知识体系,**暂不公开,仅限个人使用**。数据已编译入本插件。
