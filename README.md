# LaborPilot

> 输入案件材料,产出法律分析、金额计算和仲裁文书

[![License: AGPL v3](https://img.shields.io/badge/License-AGPL%20v3-blue.svg)](https://www.gnu.org/licenses/agpl-3.0)

**⚠️ 免责声明:所有分析结果和法律文书均由 AI 辅助生成,仅供参考,不构成法律意见,必须经专业律师审核后方可使用。**

## 它能干什么

给你一个直观感受——

**场景:员工干了3年半,公司口头通知走人,没提前30天也没给补偿。**

LaborPilot 自动完成:
- 识别为**违法解除**(§40 三要件 + 工会程序 + 通知形式逐项审查)
- 计算 **2N = 月工资 8000 × 4年 × 2 = 64,000 元**
- 引用**浙江口径**:未提前30日且未付代通知金 → 直接定性违法(2N,不是仅补代通知金)
- 给出**谈判锚点**:和解区间 N+1=40,000 至 2N=64,000
- 生成**仲裁申请书.docx**(可直接编辑提交)

再看一个——

**场景:九级工伤,月工资5500,公司没交工伤保险,想解除拿一次性赔偿。**

LaborPilot 自动完成:
- 列出**三笔一次性**(伤残补助 + 医疗补助 + 就业补助)并区分两个基数——本人工资 vs 全省社平,这是实务中最常见的算错点
- 引用**浙江月数表**:9级 = 4个月 × 社平工资
- **未参保** → 单位按条例标准全额支付(§62),不能以未参保抗辩拒付

## 快速开始

```bash
git clone https://github.com/yourname/LaborPilot.git
cd LaborPilot
```

核心功能开箱即用。可选增强:

| 功能 | 依赖 | 说明 |
|------|------|------|
| 文书生成 | [pandoc](https://pandoc.org) | md → .docx |
| 扫描件读取 | 外部 OCR 引擎 | 识别扫描 PDF / 图片 |
| 法律数据校验 | 外接 MCP 数据源 | 条文号实时核验 |

## 输入与产出

输入支持多种形式:结构化 JSON / PDF 案卷 / 图片 / 自然语言描述。引擎自动完成材料摄取和要素提取。

以 JSON 为例:

```json
{
  "case": {
    "申请人": "张某,男,1990年5月3日出生",
    "被申请人": "某科技有限公司",
    "入职日期": "2022-03-01",
    "离职日期": "2025-06-15",
    "月工资": 8000,
    "解除方式": "口头通知,未提前30日,未付补偿"
  }
}
```

```bash
python3 scripts/generate_docs.py --case my_case.json --output ./output
```

产出:

| 文件 | 内容 |
|------|------|
| 仲裁申请书.docx | 当事人 / 请求项(一、二、三…)/ 事实与理由 / 落款 |
| 证据清单.docx | 证据名称 / 来源 / 页码 / 证明目的 |
| 行动清单.docx | 待核实事实 / 待补证据 / 金额核对 / 庭前行动 |

文书模板持续更新中,支持自定义加入。

## 覆盖范围

内置 **96 个争点**,覆盖劳动仲裁全部高频案由:

| 案由 | 数量 | 覆盖内容 |
|------|------|---------|
| 解除与终止 | 15 | 协商/过失/不胜任/裁员/违法2N/被迫§38 |
| 劳动报酬 | 13 | 加班费/拖欠/最低工资/停工停产/高温津贴/年假300% |
| 经济补偿金 | 8 | N年限/封顶/代通知金/2N与N/跨2008分段 |
| 工伤保险 | 11 | 认定/停工留薪/伤残津贴/三笔一次性/工亡 |
| 竞业限制 | 2 | 补偿/违约金/司法解释(二)新规 |
| 特殊保护 | 7 | 医疗期/三期/服务期/保密 |
| 劳动关系 | 8 | 确认关系/二倍工资/试用期/劳务派遣/新就业形态 |
| 社会保险 | 5 | 补缴/养老/失业/医疗生育 |
| 程序争端 | 11 | 时效/管辖/一裁终局/举证/裁审衔接 |
| 其他 | 16 | 超龄/挂靠/事业编/用工主体责任 |

每个争点包含**浙江高院/省仲裁院裁判口径**(解答一至七/纪要/指导意见),已纳入最高法**42批指导性案例**和**《劳动争议司法解释(二)》§19**最新规则。

## 架构

```
案件材料(任意形式)
       ↓
   LaborPilot 引擎
   ├── 知识数据(96争点,预编译)
   ├── 争点路由(自动匹配案由)
   ├── 金额计算(N/2N/加班费)
   └── 文书生成(.docx)
       ↓
分析结果 + 仲裁申请书 + 证据清单
```

争点卡为作者独立构建的知识体系,**暂不公开,仅限个人使用**。数据已编译入本插件。

## FAQ

**不懂技术能用吗?**

核心用法两步:提供案件信息 + 运行生成命令。不需要编程知识。

**支持其他省份吗?**

争点框架基于国家法律法规,全国通用;地方口径当前覆盖浙江,其他省份后续开放。

**数据准确吗?**

争点数据基于浙江律协法规汇编(152部)和浙江高院解答,经执业律师审核。但所有产出由 AI 辅助生成,**必须经专业律师审核后方可使用**。
