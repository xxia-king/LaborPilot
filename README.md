# LaborPilot

> 输入案件信息,产出法律分析、金额计算和仲裁文书

[![License: AGPL v3](https://img.shields.io/badge/License-AGPL%20v3-blue.svg)](https://www.gnu.org/licenses/agpl-3.0)

LaborPilot 是一个劳动争议智能分析引擎。你提供案件的基本信息(当事人、时间线、工资标准、解除原因),它产出:

- **可主张的请求项清单**(含法律依据条文号)
- **每项金额的精确计算**(N / N+1 / 2N / 加班费三倍率 / 工伤待遇)
- **浙江裁判口径**(高院解答/纪要的最新规则)
- **证据清单和举证责任分配**
- **仲裁申请书 .docx**(可直接编辑提交)

内置 **96 个争点**覆盖劳动仲裁全部高频案由,开箱即用。

## ⚠️ 免责声明

**LaborPilot 产出的所有分析结果和法律文书均由 AI 辅助生成,仅供参考,不构成法律意见,必须经专业律师审核后方可使用。**

## 安装

```bash
git clone https://github.com/yourname/LaborPilot.git
cd LaborPilot
```

无需额外依赖。(文书生成需 [pandoc](https://pandoc.org))

## 使用

### 第一步:描述案件

创建一个 JSON 文件(`my_case.json`):

```json
{
  "case": {
    "申请人": "张某,男,1990年5月3日出生,住浙江省温州市",
    "被申请人": "某科技有限公司,住所地温州市鹿城区",
    "入职日期": "2022-03-01",
    "离职日期": "2025-06-15",
    "月工资": 8000,
    "未签书面合同": true,
    "未缴社保": true,
    "解除方式": "公司口头通知离职,未提前30日,未付补偿",
    "事实与理由": "2022年3月入职,月工资8000元。公司一直未签书面劳动合同、未缴社保。2025年6月15日公司口头通知离职,未提前30日通知,未通知工会,未支付任何补偿。"
  }
}
```

### 第二步:生成文书

```bash
python3 scripts/generate_docs.py \
  --case my_case.json \
  --output ./output \
  --types "仲裁申请书,证据清单,行动清单"
```

### 产出

| 文件 | 内容 |
|------|------|
| `仲裁申请书.docx` | 当事人 / 仲裁请求(一、二、三…) / 事实与理由 / 落款 |
| `证据清单.docx` | 证据名称 / 来源 / 页码 / 证明目的 |
| `行动清单.docx` | 待核实事实 / 待补证据 / 金额核对 / 庭前行动 |

文书模板**持续更新中**,当前支持以上三种,更多类型(答辩状/代理词/质证意见/上诉状/听证提纲等)将陆续开放,**也可以自定义加入**。

### 进阶:查特定法律问题

如果你只想查某个法律问题(不生成整套文书):

```bash
# 搜索相关争点
python3 scripts/issue_router.py --search "违法解除"

# 查看完整分析(要件/依据/算式/浙江口径)
python3 scripts/issue_router.py --search "违法解除" --full
```

## 覆盖的争点(96个)

| 案由 | 卡数 | 覆盖内容 |
|------|------|---------|
| 解除与终止 | 15 | 协商/过失/不胜任/医疗期满/裁员/违法2N/被迫§38 |
| 劳动报酬 | 13 | 加班费150%/200%/300% / 拖欠+赔偿金 / 停工停产 / 高温津贴 / 年休假300% |
| 经济补偿金 | 8 | N年限 / 三倍封顶 / 代通知金 / 2N与N关系 / 跨2008分段 |
| 工伤保险待遇 | 11 | 认定 / 停工留薪 / 伤残津贴 / 三笔一次性 / 工亡 |
| 竞业限制 | 2 | 补偿标准 / 违约金 / 司法解释(二)新规 |
| 特殊保护 | 7 | 医疗期 / 三期女职工 / 服务期 / 保密义务 |
| 劳动关系 | 8 | 确认劳动关系 / 二倍工资 / 试用期 / 劳务派遣 / 新就业形态 |
| 社会保险 | 5 | 补缴 / 养老损失 / 失业损失 |
| 程序性争端 | 11 | 时效 / 管辖 / 一裁终局 / 举证责任 |
| 其他 | 16 | 超龄 / 挂靠 / 事业编 / 用工主体责任 |

每个争点均包含 **浙江高院/省仲裁院裁判口径**(解答一至七 / 纪要 / 指导意见),已纳入最高法 **42 批指导性案例**和 **《劳动争议司法解释(二)》§19** 最新规则。

```
│  └── 文书生成(模板+格式基准)  │

    ↓
分析结果 + 仲裁申请书.docx + 证据清单.docx
```
