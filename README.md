# LaborPilot

> 中国劳动争议智能办案引擎

[![License: AGPL v3](https://img.shields.io/badge/License-AGPL%20v3-blue.svg)](https://www.gnu.org/licenses/agpl-3.0)

内置 **96 个争点**覆盖劳动仲裁全部高频案由,支持**浙江裁判口径**引用、**经济补偿/赔偿金精确计算**、**仲裁申请书一键生成**。

## ⚠️ 免责声明

**LaborPilot 产出的所有分析结果和法律文书均由 AI 辅助生成,仅供参考,不构成法律意见,必须经专业律师审核后方可使用。**

## 安装

```bash
git clone https://github.com/yourname/LaborPilot.git
cd LaborPilot
```

无需额外依赖,开箱即用。(文书生成需 [pandoc](https://pandoc.org))

## 教程

### 查案由

想知道你的案子属于哪一类?列出全部 23 个案由门:

```bash
python3 scripts/issue_router.py --list-gates
```

```
Available gates (23):
  205兜底(解除终止)  (15 cards, ZJ:14)
  205(5)追索劳动报酬 (13 cards, ZJ:13)
  205(6)经济补偿金    (8 cards, ZJ:8)
  206(2)工伤保险待遇  (10 cards, ZJ:10)
  205(7)竞业限制      (2 cards, ZJ:2)
  ...
```

### 搜争点

输入关键词,找到对应的争点卡:

```bash
python3 scripts/issue_router.py --search "违法解除"
```

```
Search '违法解除' — 12 results:
  [E10] 违法解除·赔偿金(2N)     gate: 205(6)经济补偿金 | ZJ
  [E11] 刑事责任与不予起诉解除    gate: 205兜底 | ZJ
  [E2]  过失性解除(§39六情形)   gate: 205兜底 | ZJ
  ...
```

### 看详情

查看某个争点的完整分析(构成要件/法律依据/算式/浙江口径):

```bash
python3 scripts/issue_router.py --card E10 --full
```

输出包含:
- **违法情形审查清单**(实体+程序+禁止解除对象)
- **法律依据**(劳动合同法§48/§87,实施条例§25)
- **算式**(2N = §47 标准 × 2,赔偿金年限自用工之日起算)
- **浙江口径**(未提前30日→直接定性违法/2N转N径行裁决/继续履行)
- **举证责任分配**

### 生成文书

准备案件数据 JSON,一键产出仲裁申请书 + 证据清单:

```json
{
  "case": {
    "申请人": "张某",
    "被申请人": "某科技有限公司",
    "事实与理由": "2024年3月1日入职,月工资8000元..."
  },
  "claims": [
    {"事项": "违法解除劳动合同的赔偿金", "金额": 64000, "计算式": "8000元×4个月×2"},
    {"事项": "未签订书面劳动合同的二倍工资", "金额": 88000, "计算式": "8000元×11个月"}
  ],
  "evidence": [
    {"名称": "银行工资流水", "来源": "申请人", "证明目的": "劳动关系+工资标准"},
    {"名称": "社保缴费查询单", "来源": "支付宝", "证明目的": "未缴社保"}
  ]
}
```

```bash
python3 scripts/generate_docs.py --case my_case.json --output ./output
```

产出:

| 文件 | 说明 |
|------|------|
| `仲裁申请书.docx` | 含当事人/仲裁请求(一、二、三…)/事实与理由/落款 |
| `证据清单.docx` | 含证据名称/来源/页码/证明目的 |
| `行动清单.docx` | 含待核实/待补证/金额核对(内部工作文件) |

文书模板**持续更新中**,当前支持以上三种,更多类型(答辩状/代理词/质证意见/上诉状/听证提纲等)将陆续开放。

## 争点卡体系

## 架构

```
用户输入(案件材料/关键词)
    ↓
issue_router.py ──→ _kb.pyc(预编译知识数据,96个争点)
    ↓
generate_docs.py ──→ assets/(文书模板)──→ .docx 输出
```
