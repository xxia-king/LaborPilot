# 构建你自己的争点卡

LaborPilot 的知识数据预编译在 `_kb.pyc` 中,开箱即用。
如果你想为其他省份或其他法律领域构建自己的争点卡体系:

## 卡的七节结构

```markdown
---
card_id: X01
title: 争点名称
gate: 案由门(对应官方案由)
basis:
  - {law: 法规名, article: "条号", role: 该条作用}
---

# X01 争点名称

## 构成要件
(顺序列出要件,标注举证责任方)

## 法律依据
(条文号级引用,不含条文原文)

## 举证责任与证明事项
(每项证明下列常见证据形态提示)

## 算式/后果
(计算公式、基数口径、封顶规则)

## 期限
(仲裁时效、起诉期限等)

## 地方口径
(如有本地高院解答/纪要,提炼引用)

## 文书指向
(指向 assets/ 中的文书模板)
```

## 构建流程

```bash
# 1. 将你的卡放在 cards/claims/ 和 cards/catchall/ 目录
# 2. 构建
python3 scripts/build_cards.py --cards ./my_cards --output .
# 3. 构建脚本会自动校验所有字段,100%一致才会产出 _kb.pyc
```

## 设计原则

- 条文号不带条文原文(防复用+分发安全)
- 每卡覆盖一个争点(不贪多)
- 地方口径标注来源(高院解答/纪要文号)
- 争点卡之间用 card_id 互相引用(形成知识网络)
