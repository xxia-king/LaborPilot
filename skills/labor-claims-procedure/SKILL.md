# 劳动争议金额与程序

1. 读取案件状态和上游争点结论。
2. 每项请求按标准算式逐项计算:
   - 经济补偿 N / 赔偿金 2N / 代通知金
   - 加班费(平时150%/休息日200%/法定节假日300%)
   - 工伤待遇 / 伤残津贴 / 三笔一次性
   - 竞业限制补偿
3. 数值包钩子:社平工资/最低工资/高温津贴等年度数值从数据包读取,不硬编码。
4. 浙江口径优先(如不定时无节假日加班费/加班费入补偿基数/跨2008分段)。
5. 程序路径:根据金额判断是否适用一裁终局/先予执行。
6. 时效审查:普通1年 vs 劳动报酬特殊时效。
