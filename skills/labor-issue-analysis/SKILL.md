# 劳动争议争点分析

1. 先读 `.casework/case_state.json` 确认当前阶段和代理立场。
2. **查争点卡**：运行 `python3 scripts/issue_router.py --gate "{案由门}"` 或 `--search "{关键词}"` 获取相关争点卡。每张卡包含：构成要件、法律依据（条文号级）、举证责任、算式、浙江口径和文书指向。
3. 根据代理立场分别建立我方请求／抗辩与对方最强路径，不混用立场。争点卡覆盖劳动关系、合同、解除终止、工资工时、休假、工伤社保、超龄用工、人事争议及程序问题。
4. 每个路径对照争点卡的构成要件逐项审查：已知事实、缺口、备选路径和失败后果。卡未覆盖的路径，标注"无预置争点卡"并自行构建要件。
5. 浙江口径节（如有）优先于一般规则引用。法源全文通过 `labor-authority-research` 检索。
6. 将要件和待证事实交给 `labor-evidence-analysis`。

将问题树、请求／抗辩矩阵、备选路径和对方最强观点继续写入同一份 `01_案件研判报告_vN.md`，不单独生成节点报告，不输出文书定稿。
