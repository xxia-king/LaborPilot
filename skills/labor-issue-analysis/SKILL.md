# 劳动争议争点分析

1. 读取案件状态和上游材料。
2. 根据代理立场分别建立我方请求/抗辩与对方最强路径,不混用立场。
3. 覆盖劳动关系、合同、解除终止、工资工时、休假、工伤社保、超龄用工、人事争议及程序问题。
4. 每个路径写明构成要件、已知事实、缺口、备选路径和失败后果。
5. 浙江口径节(如有)优先于一般规则引用。
6. 将要件和待证事实交给证据分析。
