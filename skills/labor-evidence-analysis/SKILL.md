# 劳动争议证据分析

1. 读取案件状态和上游争点分析中的要件和待证事实。
2. 按证明事项逐项组织证据链:每项标注举证责任方(劳动者/用人单位)和常见证据形态提示。
3. 举证责任倒置项(单位掌握的考勤/工资台账/规章制度等)标注"单位举证不能→推定劳动者主张成立"。
4. 生成证据清单:按证明事项分组,列证据名称、来源、证明目的、举证责任方。
5. 标注证据缺口和补充建议。
