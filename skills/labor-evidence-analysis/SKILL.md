# 劳动争议证据分析

1. 先读 `.casework/case_state.json` 和上游 `01_案件研判报告_vN.md` 中的要件和待证事实。
2. **查争点卡的证明事项**：运行 `python3 scripts/issue_router.py --card {卡ID} --full` 获取该争点的证明事项列表（每项标注举证责任方：[劳]=劳动者 / [单]=用人单位）和常见证据形态提示。
3. 按证明事项逐项组织证据链：每个证明事项下的证据形态仅为提示，不限定具体证据名称；个案灵活。
4. 举证责任倒置项（单位掌握的考勤/工资台账/规章制度等）标注"单位举证不能→推定劳动者主张成立"。
5. 生成 `02_证据清单_vN.md`：按证明事项分组，每组列证据名称、来源、证明目的、举证责任方。
6. 标注证据缺口和补充建议，交律师决定是否调查取证。

证据清单中的每项须与争点卡的证明事项对应；未覆盖的事项自行构建并标注。
